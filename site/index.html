First start

  • Nothing else to install: Python, CrysPy, Qt and llama-cpp-python are inside.
  • Windows may say “Windows protected your PC”: click More info → Run anyway.
  • macOS: the program is not signed by Apple. Right click it → Open → Open, or System Settings → Privacy & Security → Open Anyway.
  • The AI assistant needs a chat model: choose a downloaded .gguf file or an Ollama model in AI assistant → Load model. The model runs on your computer.

With Python

pip install cryspy_editor (add [ai] for the local AI assistant), then run cryspy-editor. Package on PyPI.
